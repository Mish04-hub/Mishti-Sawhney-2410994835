# ShopEase — Black & White CE-1 Project

A simple e-commerce cart using HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in your browser.

## Features
- Search, category and price filtering
- Sort by price/name
- Add/remove cart items and quantity controls
- Automatic subtotal, discount, shipping and total calculation
- Coupon codes: SAVE10, SAVE20, FLAT100
- Checkout form and demo order confirmation
- LocalStorage cart persistence

Checkout is a frontend demo only; it does not process payments or send orders to a server.
